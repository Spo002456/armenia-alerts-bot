# Armenia Travel Alerts → Telegram

Բոտը 20 րոպեն մեկ ստուգում է երեք պաշտոնական աղբյուր։ Ամեն նոր կամ փոփոխված նյութի համար Telegram-ով ուղարկում է առանձին հաղորդագրություններ.

1. **Նկար(ներ)**, եթե նյութում կան (լոգոներն ու պատկերակները ֆիլտրվում են)։ Մի քանի նկարը գալիս է ալբոմով, վերնագիրը՝ որպես նկարագրություն։
2. **Վերնագիր + ամբողջական անգլերեն բնօրինակ**։ Վերնագրում նշված են աղբյուրը, նյութի անունը, **հրապարակման/թարմացման ամսաթիվը Երևանի ժամով** և այն պահը, երբ բոտը ստուգել է աղբյուրը։
3. **Ամբողջական հայերեն թարգմանություն** + աղբյուրի հղում։

Տեքստը երբեք չի կրճատվում։ Եթե այն չի տեղավորվում Telegram-ի 4096 նիշի սահմանում, շարունակվում է հաջորդ հաղորդագրությունում («2/3», «3/3»...)։

| Աղբյուր | Ինչպես է կարդում | Երբ է ծանուցում |
|---|---|---|
| 🇺🇸 U.S. State Dept — Travel Advisory | RSS `travel.state.gov/_res/rss/TAsTWs.xml`, ֆիլտր՝ `Country-Tag = AM` | տեքստը, ամսաթիվը կամ մակարդակը փոխվելիս (մակարդակի փոփոխությանը 🚨 է ավելանում) |
| 🏛 U.S. Embassy Yerevan — Alerts | WordPress RSS `am.usembassy.gov/category/alert/feed/` (եթե չաշխատի, կարդում է HTML էջը) | ամեն նոր alert-ի դեպքում |
| 🇬🇧 GOV.UK — FCDO | JSON Content API `gov.uk/api/content/foreign-travel-advice/armenia` | «Latest update»-ը կամ հիմնական զգուշացումները փոխվելիս |

## Կարգավորում (մոտ 10 րոպե)

1. **Telegram բոտ.** Telegram-ում գրիր [@BotFather](https://t.me/BotFather)-ին, ուղարկիր `/newbot` և պահիր token-ը։ Հետո բոտիդ գրիր ցանկացած բան և բացիր `https://api.telegram.org/bot<TOKEN>/getUpdates`. այնտեղ `chat.id`-ն քո `TELEGRAM_CHAT_ID`-ն է։ Ալիքի համար բոտին ադմին դարձրու և որպես chat id օգտագործիր `@channelname`-ը։
2. **GitHub repo.** Ստեղծիր private repo և վերբեռնիր այս թղթապանակի ֆայլերը (`.github` թղթապանակի հետ միասին)։
3. **Secrets.** Repo → Settings → Secrets and variables → Actions → New repository secret.
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `ANTHROPIC_API_KEY` *(ընտրովի. Claude-ով ավելի որակյալ թարգմանություն է տալիս։ Եթե չկա, օգտագործվում է անվճար Google Translate-ը)*
4. **Առաջին գործարկում.** Actions → «Armenia travel alerts» → **Run workflow**։ Առաջին անգամ կգա 3 հաղորդագրություն (ամեն աղբյուրից ընթացիկ տեղեկությունը), իսկ դրանից հետո՝ միայն փոփոխությունները։

## Լոկալ գործարկում

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=...
python bot.py --dry-run   # միայն ցույց է տալիս հաղորդագրությունները, ոչինչ չի ուղարկում
python bot.py --force     # ուղարկում է բոլոր 3 աղբյուրների ընթացիկ վիճակը
python bot.py             # սովորական ռեժիմ
```

Սերվերի վրա (VPS, Raspberry Pi) կարելի է cron-ով գործարկել.
`*/20 * * * * cd /path/to/bot && /usr/bin/python3 bot.py >> bot.log 2>&1`

## Նշումներ

- **Ամսաթվերը.** State Dept-ը տալիս է միայն օրը (առանց ժամի), դեսպանությունը՝ ճշգրիտ ժամը, իսկ GOV.UK-ը՝ վերջին թարմացման ժամը։ Ժամերը փոխարկվում են Երևանի ժամանակի։
- **Նկարներ.** բոտը նկարը ներբեռնում և ուղարկում է որպես ֆայլ։ Եթե ներբեռնումը չստացվի, տեքստը միևնույն է կգա, պարզապես առանց նկարի։
- **`state.json`**-ում պահվում է, թե ինչ է արդեն ուղարկվել։ Եթե ջնջես, հաջորդ գործարկման ժամանակ նորից կգա 3 հաղորդագրություն։
- **GitHub Actions-ի cron-ը ճշգրիտ չէ.** կարող է 5–15 րոպե ուշանալ։ Բացի այդ, GitHub-ն անջատում է scheduled workflow-ները, եթե repo-ում 60 օր ակտիվություն չի եղել։ Եթե երկար ժամանակ փոփոխություն չլինի, ժամանակ առ ժամանակ մտիր և սեղմիր «Run workflow»։ Ավելի կայուն տարբերակը սեփական սերվերի cron-ն է։
- **Դեսպանության կայքը** robots.txt-ով սահմանափակում է որոշ ավտոմատ ծրագրեր։ Բոտը կարդում է միայն RSS-ը և ոչ ավելի հաճախ, քան 20 րոպեն մեկ։
